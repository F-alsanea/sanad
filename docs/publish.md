# نشر سند

سند مستودع ملفات يقرأها الوكيل. ليس حزمة npm.

الاسم المعروض: سند / Sanad
اسم المستودع: `sanad`
الدستور الداخلي يبقى اسمه FABLE حتى لا تنكسر الإحالات.

## لماذا الشكل هكذا

- `FABLE.md` كبير. تحميله كاملاً كسكيل واحد يهدر السياق.
- `skills/fable` اكتشاف قصير. الدستور ملف مرجعي.
- `app-security-gate` يُنسخ وحده إذا أراد أحد بوابة الأمن فقط.
- `templates/AGENTS.md` يُنسخ لكل مشروع. لا يُستخدم الدستور كقانون بلدية.
